# Eye Expressions
- angry_eyes | Parameters = 1| param names: angry | Notes: angry eyes are actually eyelids that extend down to half of the chao eye. Can move between 0 and 1 for anger level.
- confused_eyes | Parameters = 2 | param names: emote on, confused |
- happy_eyes | Parameters = 2 | param names: emote on, happy |
- sad_eyes | Parameters = 2 | param names: emote on, sad |
